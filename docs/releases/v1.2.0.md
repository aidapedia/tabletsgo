Tabletsgo v1.2.0 adds MariaDB as a supported database engine, so instances can now connect to MariaDB alongside PostgreSQL, MySQL, SQLite, Redis and Kafka. Operators running the Docker image should pull the new tag to make the engine available; anyone using the workspace switcher also gets a fix for reaching the admin panel.

## Highlights

### MariaDB support
MariaDB is now a first-class connection type, with the same connection fields as MySQL (`type`, `host`, `port`, `username`, `password`, `database`, `sslmode`) and the same `?database=` browsing behaviour, since its schemas are databases. It appears in the database list under **Administration → Modules**, and backups restore into MariaDB connections by replaying the dump with `mysql`. The README's supported-databases table now lists MariaDB, leaving MongoDB as the only planned engine.

### Admin panel reachable from the workspace switcher
The workspace switcher now includes a button that takes you to the admin panel, so instance administrators no longer have to leave the workspace view to get there.

### Fixes and polish
- Release notes are now generated by a script in the release workflow, so published notes follow a consistent format.
- Added internal documentation-sync tooling and skills used when maintaining the docs.

## Upgrading

Pull the new image and restart. No new environment variables or compose changes are required.
