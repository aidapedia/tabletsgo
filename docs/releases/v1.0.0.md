Tabletsgo v1.0.0 adds MySQL, Google and GitHub sign-in, and a module system where the instance admin chooses which databases and features the instance offers. It also rebuilds the console on shadcn/ui, adds per-person time zones and a workspace detail page for admins. Operators upgrading from v0.26.x should check the removed environment variables below. Everyone else gets the new features after the usual pull and restart.

## Highlights

### MySQL support
MySQL joins PostgreSQL, SQLite, Redis and Kafka as a supported database. A MySQL connection works with the same console as the other SQL engines.

### Modules
The instance admin picks which databases (PostgreSQL, MySQL, SQLite, Redis, Kafka) and features (Backups, Registration) the instance offers. This happens in the setup wizard, and can be changed later under **Administration → Modules**, which also holds each module's instance-wide settings: each database's query timeout and table row limit, and Kafka's read caps. Workspaces only see what is turned on. Turning off a database that connections still use locks those connections instead of deleting them, and emails their owners.

### Sign in with Google or GitHub
People can sign in with Google or GitHub as well as a password. The instance admin sets up the apps under **Administration → Authentication**, and each person links their accounts in **Setting → Security**. Open registration is now an optional module and is off by default. Set `PUBLIC_URL` behind a reverse proxy so the Google/GitHub callback URL and emailed links use the address people actually reach.

### Time zones
Each person picks a time zone in **Setting → Preferences**, and every time the app recorded is shown in that zone. Values stored in your own databases are shown exactly as stored.

### Workspace administration and a new home page
The instance admin gets a detail page for every workspace: what needs attention, members and roles, connections, resources and recent activity. It shows metadata only, so an admin still can't open a connection or read its credentials or queries. The workspace home page now has panels for connections, automations and recent activity, plus a getting-started guide.

### Fixes and polish
- The console is rebuilt on shadcn/ui, with a breadcrumb trail on every page, generated avatars for every person, and a reorganised settings menu.
- The API reference is now served as Swagger UI at `/api/docs` on every running instance (`server/openapi.yaml`).
- The Docker image builds faster and smaller.

## Upgrading

Pull the new image and restart. The metadata database migrates on boot and adds two migrations (linked sign-in identities and each person's time zone) for SQLite and PostgreSQL.

Removed environment variables:
- `ADMIN_USERNAME` / `ADMIN_PASSWORD`: the admin pre-seed is gone. A fresh install uses the setup wizard.
- `KAFKA_READ_MAX_MESSAGES` / `KAFKA_READ_MAX_BYTES` / `KAFKA_READ_TIMEOUT_MS`: set Kafka's read caps under **Administration → Modules** instead.
- `TABLETSGO_TAG`: `docker-compose.yml` now runs `ghcr.io/aidapedia/tabletsgo:latest`.
- `UPDATE_IMAGE`, `UPDATE_REPO`, `UPDATE_HELPER_IMAGE`, `UPDATE_AUTO_CHECK`: the in-app updater now only updates to the official release.

New and optional: `PUBLIC_URL`, the address people reach the instance at (for example `https://db.acme.com`).
