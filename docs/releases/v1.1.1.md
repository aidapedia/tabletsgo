This release updates Tabletsgo's internal release tooling and documentation workflow. It changes nothing in the running application, so operators and end users will see no difference in behaviour after upgrading.

## Highlights

### Automated release notes
The release workflow now generates release notes from a script in `.github/scripts/release-notes.mjs`, wired into `.github/workflows/release.yml` and `.github/workflows/docker-release.yml`. This affects how releases are published, not how Tabletsgo runs.

### Documentation sync tooling
New project tooling under `.claude/skills/sync-docs/` and a docs-sync reminder hook help keep documentation aligned with code changes. This is development-side only and is not part of the Docker image's runtime behaviour.

### Archived release notes
Release notes for v1.0.0 and v1.1.0 are now stored under `docs/releases/`.

## Upgrading

No action needed.
